# Latte Room (라떼방구석)

라떼방구석은 게임, 이벤트, 구독, 광고, AI 기능을 한 곳에서 제공하는 Next.js 기반 서비스입니다.

## Local Development

```bash
npm install
npm run dev
```

- Local: `http://localhost:3000`
- Build check: `npm run build`

## Deployment

- Platform: Vercel
- 기본 도메인 예시: `https://latte-room.vercel.app`

- 운영/배포/계정/결제 통합 가이드: `docs/active/OPERATIONS_GUIDE.md`
- SQL 실행 순서/재실행 원칙: `db/SQL_EXECUTION_GUIDE.md`
