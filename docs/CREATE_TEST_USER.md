# 테스트 사용자 생성 가이드

## 방법 1: Supabase 대시보드에서 직접 생성 (가장 빠름) ⭐

### 1단계: Supabase 대시보드 접속
1. https://app.supabase.com 접속
2. 프로젝트 선택
3. 좌측 메뉴에서 **"Authentication"** 클릭
4. **"Users"** 탭 선택

### 2단계: 사용자 생성
1. 상단 **"Add user"** 또는 **"Create user"** 버튼 클릭
2. **"Create new user"** 선택
3. 다음 정보 입력:
   - **Email**: `test@example.com` (원하는 이메일)
   - **Password**: 임시 비밀번호 설정 (선택사항)
   - **Auto Confirm User**: ✅ 체크 (이메일 확인 없이 바로 사용 가능)
4. **"Create user"** 버튼 클릭

### 3단계: 확인
- 생성된 사용자가 목록에 표시됨
- 이메일 주소가 보임

### 4단계: 로그인 테스트
1. 사이트에서 로그인 페이지 접속
2. 생성한 이메일 주소 입력
3. "로그인 링크 받기" 클릭
4. 이메일 확인 (또는 Supabase에서 직접 확인)

---

## 방법 2: 실제 이메일로 회원가입 (정상적인 방법)

### 1단계: 회원가입
1. 사이트 접속: `https://blog-web-five-eta.vercel.app`
2. 우측 상단 **"회원가입"** 클릭
3. 이메일 주소 입력
4. **"회원가입 링크 받기"** 클릭

### 2단계: 이메일 확인
1. 이메일 받은편지함 확인
2. Supabase에서 보낸 이메일 찾기
3. 이메일 안의 **"Confirm your email"** 또는 링크 클릭

### 3단계: 로그인
1. 로그인 페이지 접속
2. 동일한 이메일 주소 입력
3. **"로그인 링크 받기"** 클릭
4. 이메일로 받은 로그인 링크 클릭

## 추천 방법

**테스트/개발 목적**: 방법 1 (Supabase 대시보드에서 직접 생성)
- 가장 빠름
- 이메일 확인 불필요
- 즉시 사용 가능

**실제 서비스**: 방법 2 (정상적인 회원가입)
- 실제 이메일 확인
- 보안상 안전함

## 생성 후 확인 사항

1. **Supabase → Authentication → Users**
   - 생성된 사용자 확인
   - 이메일 주소 확인

2. **사이트에서 로그인**
   - 헤더에 "대시보드" 링크 표시되는지 확인
   - `/dashboard` 접속 가능한지 확인

3. **대시보드 확인**
   - 구독 상태 표시
   - 사용량 통계 표시
   - 빠른 액션 버튼 표시

## 문제 해결

### "로그인 링크를 받지 못함"
- Supabase → Settings → Auth → Email Templates 확인
- SMTP 설정 확인
- 스팸 폴더 확인

### "이메일 확인이 안됨"
- Supabase → Authentication → Users에서 사용자 선택
- "Confirm email" 버튼 클릭하여 수동 확인

### "대시보드 접속 불가"
- 로그인 상태 확인 (헤더에 이메일 표시되는지)
- 브라우저 콘솔에서 에러 확인 (F12)
