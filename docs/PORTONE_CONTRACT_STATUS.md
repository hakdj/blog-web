# 포트원 계약 상태 확인 방법

## 🎯 빠른 확인

포트원 콘솔에서 실제 결제가 가능한지 확인하는 방법입니다.

---

## 📍 1단계: 포트원 콘솔 접속

### 접속 방법
1. 브라우저에서 https://console.portone.io 접속
2. 가입한 이메일/비밀번호로 로그인

### 계정이 없다면?
- "회원가입" 클릭
- 이메일 인증 완료
- 사업자 정보 입력 (선택사항)

---

## 📍 2단계: PG 설정 확인

### 방법 1: 좌측 메뉴에서 확인

1. **좌측 메뉴 → "결제 연동"** 클릭
2. **"PG 설정"** 또는 **"결제 대행사"** 선택
3. 계약된 PG사 목록 확인

### 방법 2: 상단 메뉴에서 확인

1. **상단 메뉴 → "연동 정보"** 클릭
2. **"채널 관리"** 선택
3. 등록된 채널 목록 확인

---

## 📍 3단계: 계약 상태 확인

### 계약 상태 종류

#### ✅ 승인됨 / 활성
```
상태: 승인됨 (Active)
의미: 실제 결제 가능
조치: 바로 실제 결제 테스트 가능
```

#### ⚠️ 대기중 / 심사중
```
상태: 대기중 (Pending)
의미: PG사 승인 대기 중
조치: 3-5 영업일 대기 필요
     포트원 또는 PG사 고객센터에 진행 상황 문의 가능
```

#### ❌ 미계약 / 등록 필요
```
상태: 미계약 (Not Registered)
의미: PG사 계약 필요
조치: PG사 신청 필요 (아래 "PG사 계약 방법" 참고)
```

---

## 📍 4단계: 연동 모드 확인

### 테스트 모드 vs 실연동 모드

#### 🔵 테스트 모드
- **표시**: "테스트" 또는 "Test Mode"
- **의미**: 실제 돈이 결제되지 않음
- **용도**: 개발 및 테스트
- **카드**: 테스트 카드 번호 사용

#### 🔴 실연동 모드 (Live Mode)
- **표시**: "실연동" 또는 "Live Mode"
- **의미**: 실제 돈이 결제됨
- **용도**: 실제 서비스 운영
- **카드**: 실제 카드 사용

### 모드 전환 방법

1. **채널 관리** 페이지 접속
2. 해당 채널 선택
3. **"연동 모드"** 설정에서 변경
4. 저장

⚠️ **주의**: 실연동 모드로 전환하려면 PG사 계약이 승인되어야 합니다.

---

## 📍 5단계: API 키 확인

### API 키 종류

#### 테스트 키
```
API Key: test_로 시작
용도: 개발 및 테스트
비용: 무료
```

#### 실제 키 (Live Key)
```
API Key: live_로 시작
용도: 실제 서비스 운영
비용: 거래 수수료 발생
```

### API 키 확인 방법

1. **상단 메뉴 → "API Keys"** 클릭
2. **테스트 키**와 **실제 키** 구분 확인
3. 필요한 키 복사
   - API Key
   - API Secret
   - Webhook Secret

⚠️ **주의**: API Secret은 안전하게 보관하고, 절대 Git에 커밋하지 마세요!

## 🔍 스크린샷으로 확인하기

### 화면 예시 (제공하신 스크린샷 기준)

#### 1. 연동 정보 화면
```
좌측 메뉴: 결제 연동 → 연동 정보
상단 탭: 채널 관리 / 스마트라우팅 / API Keys / 결제창(Webhook) 관리 / 추가 설정 관리
```

#### 2. 채널 관리 화면
```
채널 목록: KG이니시스 결제창 정기결제
연동 모드: [실연동] 또는 [테스트]
결제대행사: 결제대행사를 선택해주세요
결제 모듈: 결제 모듈을 선택해주세요
```

#### 3. 확인 포인트
- **"연동 모드"** 부분이 **"테스트"**로 표시되면 → 테스트 모드
- **"연동 모드"** 부분이 **"실연동"**으로 표시되면 → 실제 결제 가능

## 🚀 PG사 계약 방법

### 계약이 안 되어 있다면?

#### 1. 포트원 콘솔에서 신청

1. **좌측 메뉴 → "PG 설정"** 클릭
2. **"PG 추가"** 또는 **"계약 신청"** 버튼 클릭
3. 원하는 PG사 선택 (KG이니시스, 토스페이먼츠 등)
4. 필요 서류 제출

#### 2. 필요 서류

**개인사업자:**
- 사업자 등록증
- 통장 사본
- 신분증 사본

**법인:**
- 법인 사업자 등록증
- 법인 등기부등본
- 통장 사본
- 대표자 신분증 사본

#### 3. 승인 기간
- **일반적**: 3-5 영업일
- **빠른 경우**: 1-2 영업일
- **늦은 경우**: 1주일 이상 (서류 보완 필요 시)

#### 4. 승인 후
- 포트원 콘솔에서 "승인됨" 상태 확인
- 실연동 모드로 전환 가능
- 실제 결제 테스트 가능

## 💡 상황별 가이드

### 상황 1: 계약 상태가 "승인됨"인 경우

✅ **실제 결제 가능!**

**다음 단계:**
1. API Keys에서 실제 키(live_) 확인
2. `.env.local` 파일에 실제 키 입력
3. `NEXT_PUBLIC_PORTONE_MODE=live` 설정
4. 서버 재시작
5. 100원 테스트 결제
6. 즉시 환불

**참고 문서:**
- `docs/SWITCH_TO_LIVE_PAYMENT.md` - 실제 결제 전환 가이드

### 상황 2: 계약 상태가 "대기중"인 경우

⚠️ **아직 실제 결제 불가**

**다음 단계:**
1. 3-5 영업일 대기
2. 포트원 고객센터에 진행 상황 문의
   - 이메일: support@portone.io
   - 전화: 1670-0876
3. 승인 완료 알림 대기
4. 승인 후 "상황 1" 참고

**현재 가능한 작업:**
- 테스트 모드로 개발 진행
- UI/UX 완성
- 다른 기능 구현

### 상황 3: 계약 상태가 "미계약"인 경우

❌ **PG사 계약 필요**

**다음 단계:**
1. 사업자 등록증 준비
2. 포트원 콘솔에서 PG사 신청
3. 필요 서류 제출
4. 승인 대기 (3-5 영업일)
5. 승인 후 "상황 1" 참고

**예상 소요 시간:**
- 서류 준비: 1-2일
- PG사 승인: 3-5 영업일
- **총 소요 시간: 약 1주일**
