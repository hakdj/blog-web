# 실제 결제 테스트 가능 여부 - 빠른 답변

## ✅ 네, 본인 돈으로 실제 테스트 가능합니다!

하지만 **현재 상태**와 **필요한 준비사항**을 확인해야 합니다.

---

## 📋 현재 상태 확인 체크리스트

### 1. 포트원 계정 상태 확인

**확인 방법:**
1. https://console.portone.io 접속
2. 로그인
3. 좌측 메뉴 → "결제 연동" → "상점 관리"

**확인 사항:**
- [ ] 계정이 있나요?
- [ ] "실제 결제" 모드가 활성화되어 있나요?
- [ ] Store ID가 발급되어 있나요?

### 2. PG사 계약 상태 확인

**포트원 콘솔에서 확인:**
- 좌측 메뉴 → "PG 설정"

**확인 사항:**
- [ ] KG이니시스 또는 다른 PG사와 계약이 완료되었나요?
- [ ] 계약 상태가 "승인됨" 또는 "활성"인가요?
- [ ] 테스트 모드가 아닌 실제 결제 모드인가요?

### 3. 사업자 등록 여부

**PG사 계약에 필요:**
- [ ] 사업자 등록증이 있나요? (개인사업자 또는 법인)
- [ ] 또는 개인 신용카드 결제 서비스를 신청했나요?

---

## 🎯 상황별 가이드

### 상황 1: 포트원 계정도 없는 경우

**단계:**
1. ❌ **실제 결제 불가능**
2. 포트원 회원가입 필요
3. PG사 계약 필요 (사업자 등록증 필요)
4. 승인까지 **3-5 영업일** 소요

**대안:**
- 현재 테스트 모드로 결제 플로우만 확인 가능
- 테스트 카드 번호로 시뮬레이션

### 상황 2: 포트원 계정은 있지만 PG사 계약이 안 된 경우

**단계:**
1. ❌ **실제 결제 불가능**
2. 포트원 콘솔에서 PG사 신청
3. 필요 서류 제출 (사업자 등록증 등)
4. 승인까지 **3-5 영업일** 소요

**대안:**
- 테스트 모드로 개발 진행
- PG사 승인 후 실제 결제 전환

### 상황 3: 포트원 + PG사 계약 모두 완료된 경우

**✅ 실제 결제 테스트 가능!**

**필요한 작업:**
1. 실제 Store ID 확인
2. 코드 수정 (아래 참고)
3. 소액 테스트 (100원~1,000원)
4. 테스트 후 즉시 환불

---

## 🔧 실제 결제로 전환하는 방법

### 1단계: Store ID 확인

**포트원 콘솔:**
1. 결제 연동 → 상점 관리
2. "실제 결제" 모드의 Store ID 복사
   - 예: `store-12345678-abcd-1234-5678-123456789abc`

### 2단계: 환경 변수 확인

`.env.local` 파일 확인:
```env
# 현재 테스트 모드인지 확인
PORTONE_API_KEY=test_xxxxx  # test_로 시작하면 테스트 모드
PORTONE_API_SECRET=test_xxxxx

# 실제 결제 모드로 변경
PORTONE_API_KEY=live_xxxxx  # live_로 시작하는 실제 키
PORTONE_API_SECRET=live_xxxxx
```

### 3단계: 코드 수정 (필요시)

현재 `lib/portone.ts` 파일은 환경 변수를 사용하므로, **코드 수정 불필요**합니다.

단지 `.env.local` 파일만 수정하면 됩니다!

### 4단계: 소액 테스트

1. **100원 플랜 생성**
   ```
   관리자 페이지 → 구독 관리 → 새 구독 추가
   - 플랜 이름: 테스트 플랜
   - 가격: 100
   - 티어: test
   ```

2. **실제 결제 진행**
   - 본인의 실제 카드 사용
   - 결제 완료 확인

3. **결제 확인**
   - 포트원 콘솔에서 결제 내역 확인
   - 카드사 앱에서 결제 알림 확인
   - 관리자 페이지에서 유료회원으로 표시되는지 확인

4. **즉시 환불**
   - 포트원 콘솔 → 결제 내역 → 해당 결제 선택 → 환불
   - 또는 관리자 페이지에서 환불 기능 사용 (구현 필요)

---

## 💰 비용 안내

### 실제 결제 시 발생하는 비용

1. **결제 금액**: 100원 (테스트용)
2. **PG 수수료**: 약 3-4원 (3-4%)
3. **환불 시**: 전액 환불 (수수료는 환불 안 됨)

**예시:**
- 100원 결제 → 실제 청구: 100원
- 환불 → 100원 돌려받음
- 손실: PG 수수료 약 3-4원

### 월 사용료

- 포트원 기본 사용료: **무료** (거래 수수료만 부과)
- PG사 월 이용료: PG사별 상이 (보통 무료~1만원)

---

## ⚠️ 주의사항

### 반드시 지켜야 할 것

1. **소액으로 테스트**: 100원~1,000원만 사용
2. **즉시 환불**: 테스트 완료 후 바로 환불
3. **본인 카드만 사용**: 타인 카드 사용 금지
4. **법적 준수**: 실제 운영 시 전자상거래법 준수

### 하면 안 되는 것

- ❌ 타인 카드로 테스트
- ❌ 고액 결제 테스트
- ❌ 환불 없이 방치
- ❌ 사업자 등록 없이 실제 판매
