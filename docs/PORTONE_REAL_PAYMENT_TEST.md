# 포트원 실제 결제 테스트 가이드

## 개요
포트원(PortOne)을 통한 실제 결제 테스트 방법을 안내합니다.

## ⚠️ 주의사항

### 테스트 모드 vs 실제 결제 모드

현재 프로젝트는 **테스트 모드**로 설정되어 있습니다:
- `lib/portone.ts` 파일에서 `storeId`가 테스트용 ID로 설정됨
- 테스트 모드에서는 실제 돈이 결제되지 않습니다
- 테스트 카드 번호로 결제 플로우만 확인 가능

## 실제 결제 테스트 방법

### 1단계: 포트원 계정 설정

1. **포트원 콘솔 접속**
   - https://console.portone.io 로그인
   - 가입한 계정으로 로그인

2. **실제 결제용 상점 ID 확인**
   - 콘솔 → 결제 연동 → 상점 관리
   - "실제 결제" 모드의 Store ID 복사

3. **PG사 설정 확인**
   - KG이니시스 또는 다른 PG사 계약 완료 확인
   - 실제 결제를 위해서는 PG사와의 계약이 필수입니다
   - 계약 완료 후 포트원 콘솔에서 PG 연동 설정

### 2단계: 코드 수정

#### `lib/portone.ts` 파일 수정

```typescript
// 테스트 모드 (현재)
const PORTONE_STORE_ID = 'store-test-xxxxx';

// 실제 결제 모드로 변경
const PORTONE_STORE_ID = 'store-xxxxx-xxxxx'; // 실제 상점 ID로 변경
```

#### 환경 변수 설정 (선택사항)

`.env.local` 파일에 추가:
```env
NEXT_PUBLIC_PORTONE_STORE_ID=store-xxxxx-xxxxx
NEXT_PUBLIC_PORTONE_MODE=production
```

그리고 `lib/portone.ts`에서:
```typescript
const PORTONE_STORE_ID = process.env.NEXT_PUBLIC_PORTONE_STORE_ID || 'store-test-xxxxx';
```

### 3단계: 소액 테스트

실제 돈이 결제되므로 **반드시 소액으로 테스트**하세요:

1. **테스트 플랜 생성**
   - 관리자 페이지에서 100원 또는 1,000원 플랜 생성
   - 테스트 후 삭제 가능

2. **실제 카드로 결제**
   - 본인의 실제 카드 사용
   - 결제 완료 확인

3. **결제 확인**
   - 포트원 콘솔에서 결제 내역 확인
   - 카드사 앱에서 결제 알림 확인
   - 관리자 대시보드에서 구독 활성화 확인

### 4단계: 결제 취소/환불 테스트

1. **포트원 콘솔에서 취소**
   - 결제 내역 → 해당 결제 선택 → 취소/환불
   - 전액 취소 또는 부분 취소 가능

2. **자동 환불 확인**
   - 카드사에 따라 즉시 또는 영업일 기준 3-5일 소요

## 실제 운영 시 체크리스트

- [ ] 정산 계좌 등록

- [ ] 이용약관 및 환불정책 명시

- [ ] 관리자 권한 강화

## 비용 안내

### 포트원 수수료
- 기본 수수료: 결제 금액의 약 3-4%
- PG사별로 다를 수 있음
- 자세한 내용은 포트원 콘솔에서 확인

### PG사 수수료
- KG이니시스: 약 3.3% + VAT
- 토스페이먼츠: 약 2.9% + VAT
- 계약 조건에 따라 협의 가능

## 테스트 시나리오

### 시나리오 1: 정상 결제
1. 100원 플랜 선택
2. 실제 카드로 결제
3. 결제 완료 확인
4. 구독 활성화 확인
5. 즉시 환불

### 시나리오 2: 결제 실패
1. 한도 초과 카드 사용
2. 에러 메시지 확인
3. 구독 미생성 확인

### 시나리오 3: 웹훅 테스트
1. 결제 완료
2. 웹훅 수신 확인 (서버 로그)
3. 데이터베이스 업데이트 확인

## 문제 해결

### 결제는 되었는데 구독이 활성화되지 않는 경우
- 웹훅 URL 확인: `https://yourdomain.com/api/webhooks/portone`
- 웹훅 서명 검증 확인
- 서버 로그 확인

### 환불이 안 되는 경우
- 포트원 콘솔에서 직접 환불 처리
- 카드사 영업일 기준 3-5일 소요
- 고객센터 문의: support@portone.io

### PG사 연동 오류
- 포트원 콘솔에서 PG 설정 확인
- PG사 계약 상태 확인
- 포트원 고객센터 문의
