# "Enable email signup" 설정 찾기 가이드

## 🎯 현재 위치
- **Authentication → Emails** 페이지에 있습니다
- 여기는 이메일 템플릿 설정 페이지입니다

## ✅ 올바른 위치

"Enable email signup" 설정은 **다른 곳**에 있습니다!

### 정확한 경로:

1. **좌측 사이드바에서 "Settings" 클릭**
   - 현재 "Authentication" 메뉴 아래에 있을 수 있습니다
   - 또는 최상단 메뉴에서 찾아보세요

2. **Settings → Auth 이동**
   - Settings 메뉴를 클릭하면
   - "Auth" 섹션을 찾아 클릭

3. **"Email Auth" 섹션 찾기**
   - Auth 설정 페이지에서
   - "Email Auth" 또는 "Email" 섹션을 찾으세요

4. **"Enable email signup" 체크 박스 찾기**
   - "Enable email signup" 또는 "Email signups" 옵션
   - 체크 박스를 **체크**하세요

---

## 📍 단계별 안내

### 방법 1: 사이드바에서 직접 찾기

1. **좌측 사이드바 확인**
   - "Settings" 메뉴 찾기
   - "Authentication" 아래가 아닌 최상단에 있을 수 있음

2. **Settings 클릭**
   - Settings 메뉴 클릭

3. **Auth 클릭**
   - Settings 하위 메뉴에서 "Auth" 클릭

4. **Email Auth 섹션 찾기**
   - 페이지에서 "Email Auth" 섹션 스크롤
   - "Enable email signup" 체크 박스 찾기

---

### 방법 2: 검색 기능 사용

1. **Supabase 대시보드 상단 검색창 사용**
   - "email signup" 검색
   - 또는 "email auth" 검색

2. **검색 결과에서 설정 페이지로 이동**

---

## 🔍 찾기 어려운 경우

### 대안: URL로 직접 이동

1. **브라우저 주소창에 입력:**
   ```
   https://app.supabase.com/project/[프로젝트ID]/settings/auth
   ```
   - `[프로젝트ID]`는 실제 프로젝트 ID로 변경

2. **또는:**
   - Supabase 대시보드 → 프로젝트 선택
   - URL 끝에 `/settings/auth` 추가
