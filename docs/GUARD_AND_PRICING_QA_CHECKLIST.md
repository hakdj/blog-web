# 권한/요금제 가드 QA 체크리스트

## 계정 시나리오
- 무료 회원
  - 관리자 페이지 접근 불가
  - 광고 등록 버튼 노출 규칙 확인
  - 구독 전용 페이지 접근 시 안내 동작 확인
- 유료 회원
  - 광고 등록 가능
  - 구독 전용 기능 정상 접근
  - 구독 만료 시 접근 차단 확인
- 관리자
  - `/admin` 및 관리자 API 접근 가능
  - 일반 사용자 전용 페이지도 정상 접근

## 결제/요금제
- 월간/연간 플랜 구독 전환 시 기간 누적 규칙 확인
- 중복 결제/중복 구독 요청 시 안전 처리 확인
- 구독 취소 후 자동 갱신 토글 동작 확인

## AI 기능 권한
- AI 키 미등록: 라떼 상담 잠금 + 안내 문구 표시
- AI 키 등록: 제공자 문구 표시 + 정상 응답
- 잘못된 키: 사용자 친화 오류 문구 표시

## 이벤트 동기화
- 동기화 버튼 수동 실행 성공 확인
- 소스별 상태 뱃지(정상/오류) 업데이트 확인
- 마지막 성공 시각 표시 확인
