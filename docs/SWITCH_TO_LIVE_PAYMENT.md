## 🔧 단계별 전환 가이드

### 1단계: 포트원 콘솔에서 실제 API 키 확인

1. **포트원 콘솔 접속**
   ```
   https://console.portone.io
   ```

2. **API Keys 탭 클릭**
   - 상단 메뉴에서 "API Keys" 선택

3. **실제 키(Live Key) 확인**
   - **API Key**: `live_` 로 시작하는 키
   - **API Secret**: 실제 결제용 시크릿 키
   - **Webhook Secret**: 웹훅 검증용 시크릿

4. **키 복사**
   - 안전한 곳에 임시 저장 (메모장 등)
   - ⚠️ 절대 Git에 커밋하지 마세요!

### 2단계: 환경 변수 파일 수정

1. **`.env.local` 파일 열기**
   ```bash
   # 프로젝트 루트 디렉토리에서
   notepad .env.local
   ```

2. **기존 테스트 키 백업** (선택사항)
   ```env
   # 백업 (주석 처리)
   # PORTONE_API_KEY_TEST=test_xxxxx
   # PORTONE_API_SECRET_TEST=test_xxxxx
   ```

3. **실제 키로 변경**
   ```env
   # Portone Configuration - LIVE MODE
   PORTONE_API_KEY=live_xxxxx  # 포트원 콘솔에서 복사한 실제 키
   PORTONE_API_SECRET=live_xxxxx  # 실제 시크릿 키
   PORTONE_WEBHOOK_SECRET=whsec_xxxxx  # 실제 웹훅 시크릿
   
   # 결제 모드 설정
   NEXT_PUBLIC_PORTONE_MODE=live  # test에서 live로 변경
   ```

4. **파일 저장**
   - Ctrl + S로 저장
   - 파일 닫기

### 3단계: 개발 서버 재시작

환경 변수 변경 사항을 적용하려면 서버를 재시작해야 합니다.

1. **현재 서버 중지**
   ```bash
   # 터미널에서 Ctrl + C
   ```

2. **서버 재시작**
   ```bash
   npm run dev
   ```

3. **환경 변수 확인**
   - 브라우저에서 관리자 페이지 접속
   - "테스트 결제" 탭 클릭
   - 상단에 "🔴 실제 결제 모드" 표시 확인

### 4단계: 소액 테스트

실제 돈이 결제되므로 **반드시 소액**으로 테스트하세요!

1. **관리자 페이지 접속**
   ```
   http://localhost:3000/admin
   ```

2. **테스트 결제 탭 선택**
   - 상단 탭에서 "테스트 결제" 클릭

3. **100원 테스트**
   - 테스트 금액: `100` 입력
   - "100원 결제 테스트" 버튼 클릭
   - 본인의 실제 카드로 결제

4. **결제 확인**
   - 포트원 콘솔에서 결제 내역 확인
   - 카드사 앱에서 결제 알림 확인
   - 관리자 페이지에서 유료회원으로 표시 확인

5. **즉시 환불**
   - 포트원 콘솔 → 결제 내역 → 해당 결제 선택 → 환불
   - 전액 환불 처리

### 5단계: 웹훅 URL 설정

실제 결제 시 결제 완료 알림을 받으려면 웹훅 설정이 필요합니다.

1. **배포된 URL 확인**
   ```
   https://yourdomain.com
   ```

2. **포트원 콘솔에서 웹훅 설정**
   - 좌측 메뉴 → "웹훅" 또는 "Webhook"
   - 웹훅 URL 입력:
     ```
     https://yourdomain.com/api/webhooks/portone
     ```
   - 이벤트 선택: "결제 완료", "결제 취소" 등
   - 저장

3. **웹훅 테스트**
   - 포트원 콘솔에서 "테스트 전송" 버튼 클릭
   - 서버 로그에서 웹훅 수신 확인

## 🔄 테스트 모드로 되돌리기

실제 결제 테스트 후 다시 테스트 모드로 돌아가려면:

1. **`.env.local` 파일 수정**
   ```env
   # 테스트 모드로 변경
   PORTONE_API_KEY=test_xxxxx
   PORTONE_API_SECRET=test_xxxxx
   PORTONE_WEBHOOK_SECRET=test_xxxxx
   NEXT_PUBLIC_PORTONE_MODE=test
   ```

2. **서버 재시작**
   ```bash
   npm run dev
   ```

## ⚠️ 주의사항

### 절대 하면 안 되는 것

1. **❌ API 키를 Git에 커밋**
   - `.env.local`은 `.gitignore`에 포함되어 있음
   - 실수로 커밋하지 않도록 주의

2. **❌ 타인 카드로 테스트**
   - 본인 카드만 사용
   - 타인 카드 사용 시 법적 문제 발생 가능

3. **❌ 고액 테스트**
   - 100-1,000원으로만 테스트
   - 고액 테스트 시 환불 지연 가능

4. **❌ 환불 없이 방치**
   - 테스트 후 즉시 환불
   - 불필요한 비용 발생 방지

### 반드시 해야 하는 것

1. **✅ 소액으로 테스트**
   - 100-1,000원 권장

2. **✅ 즉시 환불**
   - 테스트 완료 후 바로 환불 처리

3. **✅ 결제 내역 확인**
   - 포트원 콘솔에서 결제 상태 확인
   - 데이터베이스에서 구독 상태 확인

4. **✅ 웹훅 동작 확인**
   - 서버 로그 확인
   - 구독 자동 활성화 확인

### 테스트 비용

**100원 테스트 시:**
- 결제 금액: 100원
- PG 수수료: 약 3-4원 (3-4%)
- 환불 금액: 100원
- **실제 손실: 약 3-4원** (수수료는 환불 안 됨)

**월 사용료:**
- 포트원 기본 사용료: **무료** (거래 수수료만 부과)
- PG사 월 이용료: PG사별 상이 (보통 무료~1만원)

**거래 수수료:**
- KG이니시스: 약 3.3% + VAT
- 토스페이먼츠: 약 2.9% + VAT
- 계약 조건에 따라 협의 가능

**예시 (월 매출 100만원 기준):**
- 매출: 1,000,000원
- PG 수수료 (3.3%): 33,000원
- VAT (10%): 3,300원
- **실제 수령액: 963,700원**

## 🚀 배포 시 추가 작업

### Vercel 배포 시

1. **환경 변수 설정**
   - Vercel 대시보드 → Settings → Environment Variables
   - 다음 변수들을 추가:
     ```
     PORTONE_API_KEY=live_xxxxx
     PORTONE_API_SECRET=live_xxxxx
     PORTONE_WEBHOOK_SECRET=whsec_xxxxx
     NEXT_PUBLIC_PORTONE_MODE=live
     ```

2. **재배포**
   - Settings → Deployments → Redeploy

3. **웹훅 URL 업데이트**
   - 포트원 콘솔에서 배포된 도메인으로 웹훅 URL 변경

### 다른 플랫폼 배포 시

- **Netlify**: Site settings → Environment → Environment variables
- **AWS**: Systems Manager → Parameter Store
- **Docker**: docker-compose.yml의 environment 섹션

## 🔍 문제 해결

### 결제는 되었는데 구독이 활성화되지 않는 경우

1. **웹훅 URL 확인**
   - 포트원 콘솔에서 웹훅 URL이 올바른지 확인
   - HTTPS 사용 필수

2. **웹훅 서명 검증 확인**
   - `PORTONE_WEBHOOK_SECRET`이 올바른지 확인

3. **서버 로그 확인**
   - 웹훅 수신 여부 확인
   - 에러 메시지 확인

### "실제 결제 모드"로 표시되지 않는 경우

1. **환경 변수 확인**
   ```bash
   # .env.local 파일 확인
   NEXT_PUBLIC_PORTONE_MODE=live
   ```

2. **서버 재시작**
   - 환경 변수 변경 후 서버 재시작 필수

3. **브라우저 캐시 삭제**
   - Ctrl + Shift + R (하드 리프레시)

### PG사 연동 오류

1. **계약 상태 확인**
   - 포트원 콘솔 → PG 설정
   - 계약 상태가 "승인됨"인지 확인

2. **연동 모드 확인**
   - "테스트" 모드가 아닌 "실연동" 모드인지 확인

3. **포트원 고객센터 문의**
   - 이메일: support@portone.io
   - 전화: 1670-0876
